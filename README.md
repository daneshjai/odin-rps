# JS Console Rock Paper Scissors

Simple javascript console game for rock, paper, scissors.

# Skills Practiced

## Javascript

Variable scope. Simple recursive function through `getHumanChoice` function. 

Use of logical operators `&&` (and) `||` (or) and code refactoring to simplify the logic test task (i.e., just check for the human win scenarios instead of wins for each selection).

Better understanding of `cont` vs. `let` for variable declaration.

## Git

Better understanding of `git add . | <file>`, `git status` and when to use `git reset soft HEAD~1` and `git restore --staged . | <file>` and how to exiting the `git log` by pressing `q`.

`git reset soft HEAD~1` to undo the commit comment but keep the staged changes.

`git restore --staged . | <file>`  to undo the staged items or item but keep the changes.

More practice with the git workflow:

Create repo manually on gitHub -> `git clone <repo_url.git>` -> Edit files -> `git add .` -> `git status` -> `git commit -m "<comments>"` -> `git push`

## HTML

Refresher with boilerplate code for HTML in VSCode by typing `!` to generate the template.

## Terminal

More practice with `touch` to create files, `nano` for text editing, `open` to open the index.html file in Chrome, and `code` to open files in VSCode.
